## 👋 Hey, I'm Aditya

I'm a **Full Stack Developer** who enjoys turning ideas into polished, useful products.

For **4+ years**, I've been building websites and web applications for startups, businesses, and growing brands — from the first line of UI to APIs, databases, and deployment.

These days, I'm building **[Postessia](https://postessia.com)**, an AI tool that helps people write LinkedIn posts in their own voice.

I'm also diving deeper into **system design, scalable architecture, and backend engineering**.
